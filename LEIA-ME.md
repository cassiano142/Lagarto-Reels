# Lagarto Reels — arquivos prontos para o Netlify
Já está configurado com o seu Supabase. Código da rua: lagarto2026

1. Abra app.netlify.com/drop e arraste ESTA pasta (ou o zip) lá.
2. Abra o link que o Netlify der, toque em "Criar conta" e use o código da rua.
3. Para o APK: pwabuilder.com > cole o link > Package for stores > Android > Generate.
